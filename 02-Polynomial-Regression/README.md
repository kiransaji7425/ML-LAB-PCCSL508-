# Experiment 2: Polynomial Regression

## Aim
To implement polynomial regression on the Auto MPG dataset to predict Miles Per Gallon (MPG) based on engine displacement and compare it with linear regression.

## Libraries Used
- pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
Auto MPG dataset (`auto-mpg.csv`).

## Input and Output
- Input (X): Engine displacement
- Output (y): Miles Per Gallon (MPG)

## Models Used
1. Linear Regression
2. Polynomial Regression (Degrees 2, 3, 4 and 5)

## Evaluation Metrics
- Mean Squared Error (MSE)
- R-squared (R²) Score

## Result
Linear and polynomial regression models were implemented and compared using MSE and R² scores. Polynomial regression curves were visualized for different degrees.
