# Experiment 1: Simple Linear Regression

## Aim
To implement simple linear regression using the California Housing dataset to predict house prices based on average rooms per household.

## Algorithms
1. Gradient Descent
2. Normal Equation

## Dataset
California Housing Dataset (`housing.csv`)

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Evaluation Metrics
- Mean Squared Error (MSE)
- R-squared Score (R²)

## Visualization
- Regression line with actual data points.
- Cost convergence graph.
